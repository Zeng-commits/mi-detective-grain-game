# 米侦探：粮食王国大追捕

面向**小学中高年级**的粮食安全主题宣讲**互动教学游戏**。三关闯关 + 主持人控场 + 纸质线索卡，适配教室投影，**断网也能完整跑完整个教学流程**。**本游戏不做任何计分、不分小组**，主打全班互动宣讲。

> 案件中的「嫌疑犯」只是游戏角色。粮食作物本身不是坏人——真正的任务是识别目标、破解谜题，并发现粮食的重要价值。

---

## 一、最快的运行方式（推荐给老师）

**方式 A：双击打开（零依赖，最省事）**

1. 把整个 `米侦探互动小游戏` 文件夹拷到电脑（U 盘也行）。
2. 双击 `index.html`，用 Chrome / Edge 打开。
3. 点右上角 **⛶ 全屏**，或者按键盘 **F** 进入全屏投影。

> 离线可用：本游戏不依赖任何网络资源（图片、字体、音效全部本地或实时合成），教室断网照样上课。

**方式 B：本地服务器（想用 AI 助手时）**

```bash
cd 米侦探互动小游戏
node server/proxy.js
# 浏览器打开 http://127.0.0.1:8787
```

## 二、课堂使用流程（一节课约 35–40 分钟）

| 环节 | 时长 | 主持人做什么 | 孩子做什么 |
|---|---|---|---|
| 开场 | 2 分钟 | 点「开始游戏」直接进入第一关 | 听米侦探的案情播报 |
| **第一关** 粮食王国悬疑案 | 10 分钟 | 点「＋ 下一条线索」逐条揭示；孩子答错 2 次会自动补线索 | 看线索 → 举手说答案 → 上台点候选卡片 |
| **第二关** 嫌疑犯逃跑了 | 12 分钟 | 「显示题目 → 显示答案 → 显示解析 → 判答对/答错」，答对推进追击 | 举手抢答，答对可获纸质线索卡 |
| 发起纸质线索 | 2 分钟 | 转到第 3/5/7/9 题时自动提示发放，点卡片填写接收同学即可 | 领取线索卡 |
| **第三关** 最终追捕 | 8 分钟 | 引导孩子上台完成 4 个任务，揭晓真相 | 组合线索完成推理 |
| 结算 | 3 分钟 | 导出课堂记录 / 打印线索卡分发 | 看知识总结 |

### 主持人常见操作

| 操作 | 位置 | 快捷键 |
|---|---|---|
| 显示下一条线索 | 控制台「＋ 下一条线索」 | `←` |
| 显示题目 | 控制台「🎤 显示题目」 | `←` |
| 下一题 | 控制台「➡ 下一题」 | `↓` |
| 暂停 / 继续 | 控制台「⏸ 暂停」 | `空格` |
| 打开/收起控制台 | 顶栏「🎛️ 主持人」 | `H` |
| 全屏投影 | 顶栏「⛶ 全屏」 | `F` |
| 静音 | 顶栏 🔊 | `M` |

### 计分说明（本游戏不做任何计分）

- 本游戏**不做小组竞争、不显示分数、不记录正确率**。孩子的每一题回答只用来推进第二关的「追击进度」（答对越多，米侦探追得越近），以及触发纸质线索卡的解锁。
- 全程围绕**全班一起互动、一起破案**，弱化竞争、强化参与。

### 纸质线索卡（**发放权完全在老师手里**）

- 控制台「纸质线索奖励」里能看到 4 张线索卡（#1 身份证 / #2 变身术 / #3 大排行 / #4 真敌人）。
- 答对第 **3 / 5 / 7 / 9** 题时，游戏**只做一件事：解锁并提示「有线索了」**（顶部横幅 + 米侦探台词 + 控制台卡片变金色闪烁）。
- **发给哪位同学，由老师点击卡片时自行填写**（弹出框输入姓名 / 学号，并自动记住最近发放过的同学方便快速选择）。系统不会替老师决定给谁，也不会自动记录发放。
- 卡片有三种状态：`未解锁`（灰）→ `待发放`（金色闪烁）→ `已发给 XXX`（绿色）。
- 已发放的线索会在结算页生成「纸质线索卡发放记录」（含接收同学），并写入导出的课堂记录。
- 点「🖨️ 打印线索卡」打开 `print.html`：A4 纵向，一张纸上下 2 张卡，沿虚线剪开发放。
- 打印页可勾选 **打印提示语 / 打印封面卡 / 附加空白模板**（空白模板给孩子自己记录线索）。

## 三、三关内容一览

**第一关 · 粮食王国悬疑案**（识别教学）
- 3 套完整的粮食识别案件：`水稻（入门）→ 小麦（进阶）→ 大豆（高阶）`
- 每案 3–4 条线索，覆盖六个维度：外形特征、生长习性、分布区域、生产加工、营养用途、生活关联
- 答对 → 弹出六维知识卡片；答错 → 不结束，给提示；连错 2 次自动追加线索

> **防剧透设计（重要）**：第一关的简报用「调查室」、调查过程用中性的「粮食王国村庄」背景，**全程不出现目标作物的田地**，
> 案件简报里也不写「南方水田边」「麦香」这类会直接暴露答案的信息；只有在**破案之后**，场景才切换成对应的稻田 / 麦田 / 大豆田，
> 作为揭晓的奖励画面。候选对象每次进入案件都会重新打乱顺序，避免孩子靠位置猜答案。
>
> **线索文本同样不许「自报姓名」**：早期线索（第 1~2 条）不能出现作物名或该作物专属的田名，
> 例如水稻的线索不能说「稻田里蓄着水」（等于直接说了答案），只能描述成「生长时脚下常蓄着一层浅浅的水」；
> 小麦的线索也不能出现「麦穗 / 麦子」。越靠后的线索才越直白，第 4 条基本是明示，作为「再想不到就告诉你」的兜底。

**第二关 · 嫌疑犯逃跑了！**（快问快答 + 追逐）
- 主持人控场的快问快答，答对米侦探向前追击，答错停滞
- 题库覆盖三类：**粮食知识 / 生活常识 / 粮食安全**，三档难度：**简单 / 中等 / 挑战**
- 难度自适应：连错 2 题自动降到「简单」，连对 2 题自动升到「挑战」

**第三关 · 最终追捕与粮食王国的秘密**（综合推理）
- 任务一：组合线索锁定神秘访客（玉米）
- 任务二：粮食 ↔ 食品配对（小麦/水稻/大豆/马铃薯）
- 任务三：挑出 3 个浪费粮食的行为
- 任务四：选出 4 个保护粮食安全的正确做法
- 揭晓真相：敌人不是某种粮食，而是 **粮食浪费 · 自然灾害 · 耕地流失**
- 通关动画 + 徽章 + 粮食安全知识总结

## 四、题库结构（方便老师自行扩题）

文件：`js/data-questions.js`，格式：

```js
{
  id: "Q-S-006",              // 唯一编号（Q-K 识别 / Q-L 生活常识 / Q-S 粮食安全 / Q-C 挑战）
  category: "粮食安全",        // 粮食知识 | 生活常识 | 粮食安全 | 挑战
  difficulty: "medium",        // easy | medium | hard
  question: "题干文字",
  options: ["选项1", "选项2", "选项3", "选项4"],   // 必须 4 个
  answer: 0,                   // 正确选项下标 0-3
  explanation: "答案解析",
  funFact: "有趣的补充知识",
  tags: ["耕地保护"],
  source: "常识",              // 或「国家统计局2025年12月12日公告」
  reviewed: true
}
```

**默认题库统计**：共 45 题 —
`粮食知识 10 题` + `生活常识 15 题` + `粮食安全 15 题` + `挑战 5 题`；
难度分布 `简单 15 / 中等 25 / 挑战 5`。

> 改完题库后刷新页面即可生效，无需编译。

**作物档案与线索**在 `js/data-crops.js`（`window.CROPS`），
**案件与最终推理**在 `js/data-cases.js`（`window.CASES` / `window.FINAL_CASE` / `window.PAPER_CLUES`）。

## 五、AI 接口配置（可选）

**默认是离线模式**：不配 AI 也能玩完整流程，全部使用已人工审核的默认题库。

AI 在游戏中扮演「智能调查助手」，只做 5 件事：

| 能力 | 说明 | 离线回退 |
|---|---|---|
| 智能生成线索 | 按目标作物生成由易到难的线索 | 从已审核线索库按序取 |
| 智能解释答案 | 用孩子能懂的话解释 + 补充趣味知识 | 用题库自带的解析与 `funFact` |
| 智能调整难度 | 连错降难度、连对升难度 | 纯本地策略（本来就不需要联网） |
| 智能生成题目 | 按主题/难度出题 | 从已审核题库抽题 |
| 扮演米侦探 | 转场、反馈时说一句角色台词 | 使用预置台词库 |

### 安全铁律（已内建）

- ✅ AI **不能改变标准答案**。判定永远以已审核题库为准。
- ✅ AI 生成的题目默认标记 `reviewed:false`，前端**不会采用**；只有带 `reviewed:true` 的才会显示。
- ✅ 涉数字时必须引用**国家统计局 2025 年 12 月 12 日公告**的数据，禁止凭印象回答。
- ✅ 任何 AI 调用失败/超时，**静默回退到本地内容**，课堂不会中断。

### 怎么开启

1. 在 `index.html` 里填上你的服务端代理地址：

```html
<script>
window.MI_AI_CONFIG = {
  endpoint: 'http://localhost:8787/api/mi',
  model: 'gpt-4o-mini',
  timeout: 6000
};
</script>
```

2. 启动代理时把密钥通过**环境变量**传入（密钥绝不写进前端）：

```bash
# Windows PowerShell
$env:MI_API_KEY   = "sk-你的密钥"
$env:MI_API_BASE  = "https://api.openai.com/v1"     # 换成你使用的服务商地址
$env:MI_MODEL     = "gpt-4o-mini"
node server/proxy.js
```

```bash
# bash / macOS / Linux
MI_API_KEY=sk-你的密钥 MI_MODEL=gpt-4o-mini node server/proxy.js
```

代理只暴露白名单任务，并在返回前**二次校验题目结构**（必须 4 个选项 + 合法答案下标），不合格就不返回，由前端回退本地题库。

> ⚠️ 不要在前端代码、也不要提交到 Git 里放密钥。若使用商业大模型服务，注意其内容安全策略是否满足校园使用要求。

## 六、离线运行方案（教室断网）

本游戏在设计上**不依赖任何在线资源**：

- 所有图形（米侦探形象、10 个场景）都是**内联 SVG**，没有一张图片文件。
- 音效由 **Web Audio API 实时合成**，没有音频文件。
- 默认题库、线索、案件、知识卡片全部打包在 `js/` 目录里。
- 计分与进度用浏览器 `localStorage` 暂存，**不上传任何数据**。

所以只要文件夹在本地，双击 `index.html` 就能完整上课。

## 八、常见问题

**Q：投影后排看不清怎么办？**
按 `F` 全屏；界面字号使用 `clamp()` 随屏幕放大，1700px 以上会自动加大题目与选项字号。建议浏览器缩放保持 100%。

**Q：孩子想自己操作答题？**
第三关就是给孩子上台点选的。第一、二关也可以直接让孩子点候选卡片/选项，主持人只负责控场。

**Q：不小心点错了/想重来某一关？**
控制台「关卡跳转」可以随时切到任意一关；「重新开始」会清空进度与分数（会二次确认）。

**Q：统计数字是哪年的？**
题库中凡涉及中国粮食产量、播种面积、单产的题目，统一标注来源为 **国家统计局 2025 年 12 月 12 日《关于 2025 年粮食产量数据的公告》**
（2025 年全国粮食总产量 **14297.5 亿斤**，播种面积 **17.91 亿亩**，单产 **399.1 公斤/亩**）。改题时请沿用同一来源，不要把过时数据当最新数据使用。
